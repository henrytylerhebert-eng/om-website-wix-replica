# OM Website — Tyler Working Copy / Reference

This is Tyler's temporary personal copy/reference build of
`robertehebert.wixstudio.com/opportunity-machine`, plus one sandboxed concept
(`clarity-check.html`). It is a copy-dialing and comparison surface while the
new site takes shape. It is not the current website, the new-site source of
truth, or a launch artifact, and its relevance should decline as the new site
becomes authoritative.

**Not approved public copy.** The working reference intentionally preserves
items flagged for review (including unsourced stats, pending-consent
testimonials, and uncleared partner logos) so Tyler can compare and revise them
with claim-flag outlines (press `C` on any page to toggle). Search engines are
asked not to index this via `robots.txt`; the URL is still publicly reachable,
so treat it as unlisted rather than private and do not share it as an approved
site.
